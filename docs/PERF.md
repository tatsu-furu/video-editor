# 性能の記録（設計書 12.1）

## 2026-10-03：開発環境（クラウドのサンドボックス）での計測

GPU なしの Linux サーバー上の Chromium（headless）で計測した。**一般的なゲーミング PC を基準とする設計書の目標とは条件が違う**ので、参考値として扱い、実機（Chrome / Edge、独立 GPU あり）で計測し直すこと。

素材は ffmpeg で作った 10 分の WebM（320×180・30fps・VP9 / Opus、7 秒周期で音と無音が交互）。この環境の Chromium には H.264 / AAC のエンコーダーが無いため、書き出しは VP9 / Opus になっている。

| 項目                          | 目標                      | 計測値                                  | 備考                                                                        |
| ----------------------------- | ------------------------- | --------------------------------------- | --------------------------------------------------------------------------- |
| 音声解析（エンベロープ＋VAD） | 1時間で3分以内            | 10分の素材で 5.6 秒                     | VAD は音量による代用（Silero VAD のモデルを取得できない環境のため）         |
| 分割の反映                    | 50ms 以内                 | 0.8 ms                                  | `S` キーを押してから次の描画まで                                            |
| 候補 86 件の一括適用          | 50ms 以内                 | 約 110 ms                               | クリック〜画面更新まで（Playwright 経由の計測。操作のオーバーヘッドを含む） |
| 書き出し                      | 実時間以下                | 5分39秒の出力（クリップ 87 本）を 24 秒 | 320×180 なので 1080p の参考にはならない                                     |
| 末尾の A/V ずれ               | 1 フレーム以内            | 映像 5:38.66 / 音声 5:38.68（差 20ms）  | 30fps の 1 フレーム = 33ms                                                  |
| 書き出しのラウドネス          | −14 ±1 LUFS、−1 dBTP 以下 | −14.0 LUFS、ピーク −12.3 dBFS           | `ffmpeg -af ebur128=peak=true`                                              |

## 未計測（実機で計測すること）

- 1時間・1080p60 の OBS 録画（MP4・MKV）の読み込みと解析、メモリ使用量（2GB 以内）
- 1080p30・10分の書き出し時間と、書き出し中のメモリ推移（DevTools の Performance / Memory）
- 書き出し中に別のタブへ切り替えたときに最後まで終わるか
- タイムライン操作（500 クリップ）のフレームレート
- プレビューのカット境界での途切れ（100ms 以内）
- Whisper（WebGPU / WASM）での 5 分の日本語素材の文字起こし時間
